# 快速上手 · 简体中文

[English](guide.en.md) · [项目](../README.zh-CN.md)

## 打开软件

1. 完整解压 Windows x64 ZIP，双击 **VisualAudioNotes.exe**，保留旁边的 `_internal` 文件夹。
2. 顶栏选择 **简体中文**，软件会记住。切换语言不会翻译原件或已有笔记。
3. 点击 **导入资料**，一起选择课件、图片和一段录音。SRT/VTT 可选；后拿到的资料可用 **添加资料** 补入原项目。
4. 点击 **开始整理**，核对结果后 **保存归档**。

无需安装开发工具。程序依赖系统 WebView2 Runtime 和 .NET Framework 4.x；缺少 WebView2 时可从 [Microsoft 官方页面](https://developer.microsoft.com/microsoft-edge/webview2/) 安装。预览版未签名，不以关闭安全软件作为使用步骤。

## 首次设置

设置分三个独立能力页：

- **语音识别**：完整版自带本机 Whisper 引擎。首次明确点击准备约 **486 MB** 语音模型，有进度、校验、续传和停止；打开程序不会自动下载。准备后可离线转写，也可填写自己的兼容语音 API 地址、模型名和密钥。接口必须返回 Whisper 风格分段时间戳，普通聊天模型不能自动代替。录音语言可选中文、英文或自动。
- **图片识字**：完整版自带本机中英 RapidOCR，只处理没有原生文字的页。也可设置 DeepSeek 视觉识字适配器。OCR 识字不代表理解图表或流程。
- **重点归纳**：接入自己的 DeepSeek 文字 API 或本机 llama.cpp 服务，DeepSeek 默认关闭思考。没有文字连接也能识别、手记和归档。新 AI 草稿按当前界面语言生成，原文引述和代码保留原语言。

API 轻量版不含本机识别引擎，需要自己的语音和图片接口，或改用完整版。各能力密钥独立，文字密钥不会自动发给语音服务。默认只在本次使用；勾选记住后由 Windows 当前用户加密保存。

## 核对并保留成果

- 建议页可以先预览，只有 **确认对应** 或 **确认无对应** 才记录决定，不自动确认。
- **修正这段转写**、**修正识别文字** 保留原件及原始识别。变更内容后旧对应和主题需复核，未变的有效模型步骤可复用。
- 切换语言、添加资料或归档前，请保存或取消文字修订；语言和连接设置须在任务停止后修改。
- **停止整理** 不再新增请求，已发送请求不能撤销，仍可能计费；以后可继续复用已完成结果。
- 中文归档打开 **阅读.html** 或 **笔记.md**。英文归档打开 **index.html** 或 **notes.md**，保留原格式记录及兼容阅读入口。已有模型草稿不会因导出语言改变而自动翻译。请保存整个文件夹，保留音频、相对链接、原件哈希、原始/修订字幕、证据和用量。

## 文件支持与边界

PDF、PNG/JPG、PPTX、DOCX、XLSX、VSDX、WAV/MP3/M4A、SRT/VTT；每项目一段原录音、一份用户字幕。后补用户字幕可替代自动转写，旧转写仍保留。同名但内容不同的文件会被拒绝，不覆盖原件。

现代 Office 直接读文字及支持图片，内置预览只是阅读视图。Word 阅读页不是原始页码；Excel 公式不重算；Visio 端点不等于箭头语义。旧 `.ppt/.doc/.xls/.vsd` 需要已安装的转换组件。

默认数据位于 `%LOCALAPPDATA%\VisualAudioNotes`。原始导入文件不会被修改，删除软件解压目录也不会删除工作区；删除工作区前先保存归档。

步骤复用、稳定前缀与调用上限减少重复调用。默认每轮识别与归纳合计最多 32 次新请求，并限制请求的最大输出预算。语音提交时长、服务报告时长、文字 token 与未知用量分开记录，实际计费以供应商为准，节省金额尚未做线上对照。

当前是预览版，剩余质量与普通用户验证见 [1.0 清单](ROADMAP.md)。
